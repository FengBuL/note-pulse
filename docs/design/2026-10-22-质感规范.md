# 看板质感规范

适用范围：看板（`.vp-` 样式）。重复内容清理页（`.cd-`）和写作报告弹窗后续按同一规范迁移。

参考图：同目录 `2026-10-22-质感参考/v2-*.png`（示例数据画的静态示意）。

## 原则

1. 层级先于装饰。一张卡只有一个主数字，其余信息退为辅助。
2. 渐变只走一条色带：强调色 → 玫瑰色。强调色取用户主题的 `--interactive-accent`，玫瑰色由它混出来，换主题时整体跟着变。
3. 同一个指标在页面上只出现一次。
4. 列表不留死路：超出部分可以展开或跳转，不写一行点不动的“还有 N 项”。
5. 数字必须有来源。没有数据的指标不画，不估造。

## 令牌

| 类别 | 令牌 | 取值 |
|---|---|---|
| 字号 | `--vp-fs-11` `--vp-fs-12` `--vp-fs-13` `--vp-fs-15` `--vp-fs-20` `--vp-fs-28` `--vp-fs-40` | 11 / 12 / 13 / 15 / 20 / 28 / 40 px |
| 字重 | 400 / 500 / 600 | 正文 / 标签 / 标题和数字 |
| 圆角 | `--vp-r-s` `--vp-r-m` `--vp-r-f` | 6px 小控件 · 12px 卡片 · 999px 胶囊 |
| 阴影 | `--vp-shadow` `--vp-shadow-raise` | 静止 · 悬停抬起 |
| 时长 | `--vp-t-fast` `--vp-t-base` | 120ms 悬停按下 · 240ms 展开切换 |
| 曲线 | `--vp-ease` | `cubic-bezier(0.2, 0, 0, 1)` |
| 间距 | `--vp-s1` … `--vp-s6` | 4 / 8 / 12 / 16 / 24 / 32 px |
| 颜色 | `--vp-accent` `--vp-accent-2` | 主题强调色 · 强调色混玫瑰色 |
| 渐变 | `--vp-grad` | `linear-gradient(135deg, accent, accent-2)` |

字号用途固定：40 今日连续天数，28 数据卡主数字和页首总结句，20 次级数字，15 页首副句，13 正文，12 标签与说明，11 坐标轴和图例。

`npm run check:tokens` 检查看板样式区里没有直接写 px 字号、圆角、阴影和时长。

## 数字排版

- 主数字：字重 600，字距 -0.03em，等宽数字。
- 单位：13px、字重 500、次要色，与数字基线对齐。
- 变化值：统一一种胶囊（上升绿、下降红、持平灰）。

## 交互

- 数据卡小趋势线：悬停或键盘左右键移动时，卡片主数字换成该周的值并变为强调色，右侧显示日期胶囊和该周变化；移开恢复。
- 本周打卡：圆点和柱状两种，卡片上切换，记住选择。
- 库体检：随看板刷新实时计算，每项旁边带可直接执行的操作；会改动笔记的操作一律先进入预览，可撤销。

## 动效（2026-10-23 加入）

实现在 `src/motion.ts`（数字滚动、高度过渡、分段滑块、走势线描线、错开次序）和 `styles.css` 的“动效”一节。

1. 只在三种时候动：首次打开看板、用户操作（切换、展开）、数值真的变了。自动刷新默认库改动 3 秒后整页重绘，如果每次都重放，写笔记时看板会一直在动。
2. 首次打开：卡片按顺序浮现（`--vp-enter` 0–0.6 × `--vp-t-stagger`），卡片里的行、条形、柱子、热力图列再按 `--vp-i` 错开。`onOpen` 之后紧跟的那次刷新如果落在首次动画期间，用负延迟接着放，不重头来。
3. 自动刷新：数字从旧值滚到新值并短暂换成强调色；没变的数字和卡片不动。
4. 切换（swap）：内容淡入、图表重新长出、分段控件的选中底色滑到新位置、卡片高度过渡。展开收起（resize）只过渡高度。
5. 展开的列表在卡片内限高滚动（`--vp-scroll-max`），不拉长整页；库体检一次只展开一栏。
6. 设置里可以关；系统“减弱动态效果”时一律不动（JS 动画看 `matchMedia`，CSS 看媒体查询）。
7. 不用 View Transitions 和 `clip-path` 动画：iOS 16.4 不支持或只部分支持（`npm run check:css` 会报）。

| 令牌 | 取值 | 用途 |
|---|---|---|
| `--vp-t-enter` | 480ms | 卡片、行入场 |
| `--vp-t-grow` | 720ms | 条形、柱子长出 |
| `--vp-t-step` / `--vp-t-cell` | 40ms / 30ms | 行之间 / 热力图列之间的错开 |
| `--vp-t-stagger` | 600ms | 首次打开最后一张卡的延迟 |
| `--vp-t-flash` | 1300ms | 数值变化后的强调色 |
| `--vp-ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 入场 |

JS 里的毫秒值在 `MOTION` 常量里，与上表保持一致。
